01What imposition means

A printer does not print one business card at a time. It prints a big sheet of paper and cuts it up afterwards. Your job is to hand over a file where the cards are already arranged on that big sheet, in a grid, the right way up, with the backs matching the fronts.

Arranging them is imposition. Doing it by hand in Figma means copying, pasting and nudging dozens of frames and hoping nothing drifted by half a millimetre. This plugin builds the sheet from numbers instead.

02Install

Impose Pro is published on the Figma Community, so you do not need any files from this computer. Install it from inside Figma.

Recommended — install from the Community

  1. Open Figma.

    The desktop app or figma.com in a browser both work for installing.

  2. Search the Community for “Impose Pro”.

    Click the Figma logo in the top-left corner to reach your files list, then choose Community in the left sidebar and type Impose Pro into the search box. Set the filter to Plugins if you see files and templates mixed in.

  3. Open the plugin page and click Open in… or Try it out.

    Figma saves it to your account. From then on it appears in every file you open — it is tied to your login, not to this computer.

  4. Run it from any design file.

    Open a design file and use the menu path shown in Opening the plugin below.

i

If you are testing a newer, unpublished build — for example a fix that is not on the Community yet — install the local folder instead. In the Figma desktop app (this does not work in a browser), go to Plugins → Development → Import plugin from manifest… and pick manifest.json inside:

D:\Documents\Plugins\Impose Pro 3 - Final\manifest.json

That folder is the current build. The other Impose Pro folders and zips are older iterations — ignore them.

03Opening the plugin

Open any Figma design file first. The plugin needs a file to work in.

Then right-click on empty canvas, or use the main menu:

Plugins → Impose Pro
!

Installed but not in the menu? If you imported the local folder rather than installing from the Community, it lives one level deeper: Plugins → Development → Impose Pro.

04Tour of the panel

The panel is long. It divides into four bands, and it is worth knowing what lives where before you start hunting for a control.

BandWhat is in it
Select Job Whole saved configurations. Save Job, Export Job, Import Job, Delete Job, plus an optional job name. Export/Import are files, so a job can be handed to a colleague.
Global Settings Load Selected Artwork and Load Template Frame, the artwork thumbnails, Organize Pages, Template Library, then Units (inches or mm), Binding, Sheet Preset and the sheet width/height — with Save Sheet Preset and Export Sheet Preset.
Layout & Export Settings Applied to the output page as a whole: spacing between frames, layout direction, and output mode (vector and keep editable, or flattened).
Sheet Set 1, 2, 3… One block per sheet. Inside each: a live front and back preview; Layout (columns, rows, gutter X/Y, artwork behaviour, duplex, fit & align, and an Add Libre Barcode 39 tick); and Transform (per-side rotation and shift X/Y). Each set also has its own Copies count, Apply to all sheets, Load Template and Remove Sheet.
i

Two controls worth knowing about now.

Copies — on each sheet set. This is how you get quantity: set Copies to 25 and that sheet is output 25 times. Apply to all sheets pushes one sheet set’s settings onto every other, which saves a lot of retyping on multi-sheet jobs.

Units — the whole panel switches between inches and millimetres. Every field described below follows whichever you picked, so if you work in mm, set it once at the top and ignore the inch references.

051 · Load your artwork

The plugin does not guess what to impose. You tell it, by selecting frames on the canvas and pressing a button.

  1. Click your artwork frame on the canvas.

    Click the frame’s name label just above its top-left corner — that selects the whole frame rather than something inside it. To select several, hold Shift and click each one, or drag a selection box around them all.

  2. Check what you selected.

    Figma highlights each selected frame with a blue outline. Only frames, components, instances and groups can be imposed — a loose rectangle or a bare text layer will be ignored.

  3. Click Load Selected Artwork in the plugin panel.

    The panel fills in how many pieces it found and their real size in inches, and thumbnails appear in the artwork gallery. If it says nothing was loaded, your selection did not contain a frame — go back to step 1.

i

Order matters if you picked more than one. The plugin uses them in the order you loaded them. For a booklet, that must be reading order: page 1 first.

062 · Set the sheet size

The sheet is the piece of paper the press will actually feed. Pick the preset that matches the stock you are printing on, or type your own dimensions.

  1. Find Sheet Preset in Global Settings.

    Just under Binding. Set Units above it first if you work in millimetres.

  2. Choose a preset, or choose Custom.

    Presets are 13×19, 12×18 and 11×17 inches.

  3. If Custom: type width and height in inches.

    Inches, not millimetres and not pixels. 8.5 and 11 for US Letter. Decimals are fine.

073 · Set the grid

The grid is how many copies fit across and down. Columns is across, rows is down. Gutters is the gap between them.

i

These live inside a Sheet Set, in its Layout column — not in Global Settings. So does artwork behaviour, duplex and fit & align. Each sheet can therefore be laid out differently; use Apply to all sheets when you want them identical.

  1. Type a number of columns and rows.

    Work it out roughly first: sheet width ÷ artwork width, rounded down. A 3.5 in card on a 13 in sheet gives 3 columns with room to spare.

  2. Add gutters if the printer needs cutting room.

    Leave gutters at 0 to butt the pieces against each other and share one cut line — cheapest, most common. Add a gutter when each piece needs its own cut, or when artwork bleeds past its trim.

  3. Watch for an overflow warning.

    If the grid no longer fits the sheet, the plugin tells you instead of silently cropping. Reduce columns, rows or gutters until the warning clears.

084 · Repeat or Unique

This decides what goes in each cell.

095 · Simplex or Duplex

Simplex is printed on one side. Duplex is printed on both. Choosing Duplex makes the plugin build a matching back sheet for every front sheet, so the backs land behind the right fronts when the paper is flipped.

!

Duplex plus Unique needs double the artwork. A 2×2 grid in duplex is 8 frames — 4 fronts and 4 backs. Load them front, back, front, back in that order. Load too few and the plugin refuses rather than filling gaps at random.

106 · Fit & align

Two options that answer the question “when the artwork and the cell are not the same size, who wins?”

01

Center to Sheet

Cells are sized to your artwork, and the whole block is centred on the sheet. Margins land evenly around the outside. This is what you want for cutting.

02

Center to Cell

Cells divide up the whole sheet, and artwork is centred inside each one. Use it when the grid must fill an existing die or template.

117 · Rotation and shift

These are set per side — front and back have their own values — for cases where the press or the die needs the art turned or nudged.

  • Rotation — 0°, 90°, 180° or 270°. Rotating 90° often fits more pieces on a sheet: a landscape card may go 4-up rotated where it only went 3-up upright.
  • Shift X / Shift Y — moves that side by a distance in inches. This is the fix for a press whose duplex registration is out by a known amount; shift the back to compensate rather than re-cutting.
i

Leave both at 0 unless you have a reason. If a printer has not told you to shift anything, you do not need to shift anything.

128 · Impose

  1. Check the preview in the panel.

    The preview is drawn from the exact same layout maths as the output, so what you see is what gets built. If the preview looks wrong, the output will be wrong — fix it here, not after.

  2. Click Impose.
  3. Look for the new page.

    The plugin creates a whole new Figma page named Impose Pro Output - [date] and puts the finished sheets on it. Your original artwork is never touched or moved.

  4. Export that page to PDF.

    With the output page open, use File → Export frames to PDF…. Each sheet frame becomes one PDF page, in order. Send that PDF to the printer.

i

Ran it twice? Each run makes its own dated page, so nothing is overwritten. Delete the pages you do not want — right-click the page name in the left sidebar → Delete page.

13Booklets & binding

A booklet is not just a grid. If you fold a stack of paper in half, the page that has to sit next to page 1 is the last page — not page 2. Getting that ordering right by hand is where people lose an afternoon. The Binding setting does it for you.

Set Binding in Global Settings, and the plugin takes over the grid, duplex, behaviour and sheet count automatically. Rotation, shift and gutters stay yours to edit.

Saddle Stitch

Fold the whole stack down the middle and staple through the spine. Sheets are built as 2-up duplex printer spreads.

Perfect Bind (cut & stack — 1 book)

For a squared-off spine that gets glued rather than stapled. Sheets are 2-up duplex leaves: the left column carries the first half of the book, the right column the second half.

Perfect Bind (cut & stack — 2 books)

Same idea, but the same leaf is printed in both columns. One cut gives you two complete identical books, which doubles throughput on short runs. Page count is padded to a multiple of 2 rather than 4.

Rules that apply to every binding

  • Load your pages in reading order — page 1 first — then choose a binding.
  • Page count is padded up to a multiple of 4 with blank cells at the end (except the 2-book mode, which pads to 2).
  • The artwork gallery and Organize Pages always show the book in reading order — the way a reader sees it. The scrambled printer ordering is applied underneath, only in the sheet previews and the output. Do not try to pre-scramble your pages; you will get it twice.

14Barcodes, templates and output mode

Three things in the panel that the workflow above does not need, but which exist for real jobs.

01

Add Libre Barcode 39

A tick box in each sheet set’s Layout column, with a code field and a choice of which side it prints on. It renders using the Libre Barcode 39 font, so that font has to be installed and available to Figma — it ships in the plugin folder under Font\LibreBarcode39\. Without it the barcode renders as plain text.

02

Template Frame & Template Library

Load Template Frame reads one or two selected frames as a sheet template — a die layout you impose into rather than an even grid. Saved templates live in the Template Library and can be applied per sheet set with Load Template. There are worked examples in the plugin folder under Presets\.

03

Output mode

In Layout & Export Settings. Vector – keep editable is the default and what you want. The flattened options rasterise each placed page instead — useful only when heavy effects or transparency are causing export trouble.

04

Organize Pages

Reorders the loaded pages before imposing. It always shows the book in reading order, even when a binding is active and the printed order is scrambled underneath.

15Presets and jobs

Once a job is dialled in, save it. There are two levels: a Sheet Preset (just the sheet size) and a Job (the entire configuration — every sheet set, grid, transform and copy count). Both can be exported to a file and imported on another machine, so next month’s reprint is two clicks instead of twenty fields.

  1. Configure everything the way you want it.
  2. Find the preset controls and click Save.

    Give it a name that will mean something later — Door hanger 10-up 13x19 beats test2.

  3. Next time, load the preset instead of retyping.

    Then just load the new artwork and press Impose.

i

There are ready-made presets in the plugin folder under Presets\ — including sheet sizes and door-hanger templates — if you want examples to start from.

16Worked examples

50 business cards on one sheet

  1. Design one card at 3.5 × 2 in.
  2. Select it → Load Selected Artwork.
  3. Sheet: 13×19. Grid: 5 columns × 10 rows. Gutters: 0.
  4. Behaviour: Repeat. Duplex if the card has a back.
  5. Impose → 50 cards on one sheet.

A 16-page booklet

  1. Design all 16 pages as separate frames, same size.
  2. Select them in reading order → Load Selected Artwork.
  3. Set Binding to Saddle Stitch. The grid and duplex settings lock themselves to what the binding needs.
  4. Impose → 4 sheets, 8 sides, correctly ordered.
  5. Export to PDF, print duplex, fold, staple.

Mixed postcards, one per agent

  1. Make one frame per agent — say 9 of them.
  2. Select all 9 → Load Selected Artwork.
  3. Grid 3 × 3. Behaviour: Unique.
  4. Impose → one sheet, nine different postcards.

17When something goes wrong

SymptomCause and fix
“No artwork loaded” Nothing valid was selected when you pressed the button. Select frames on the canvas first, then click Load Selected Artwork. Only frames, components, instances and groups count.
“Not enough artwork for unique mode” Unique needs one frame per cell, doubled for duplex. A 2×2 duplex grid needs 8 frames. Load more, shrink the grid, or switch to Repeat.
Artwork comes out the wrong size The plugin uses your frames’ real dimensions — so the frame itself is wrong. Check it in Figma’s right-hand panel. This build treats 1 inch as 72 px, so an 8.5×11 in page is 612×792 px.
Overflow warning that will not clear The grid is genuinely bigger than the sheet. Reduce columns, rows or gutters — or rotate 90°, which sometimes buys a whole extra column.
Backs land behind the wrong fronts In Unique + Duplex the load order must be front, back, front, back. Reload in that order. If registration is out by a fixed amount, use Shift on the back side.
Booklet pages read out of order Pages were loaded pre-scrambled. Load them 1, 2, 3… and let the binding do the reordering.
Panel shows a hardcoded 8.5×11 and ignores you An old build is loaded. Re-import from the Impose Pro 3 - Final folder, or reinstall from the Community.
i

Golden rule. The preview and the output are generated from the same layout model — so the preview never lies. If the sheet is wrong after imposing, the preview was wrong before it, and that is the cheaper place to catch it.

18The Illustrator edition

Everything above is the Figma plugin. The same interface also runs inside Adobe Illustrator as a CEP panel — literally the same ui.html, with the backend rewritten. Artboards become the pages, and instead of building an output page for you to export by hand, it writes a press-ready multi-page PDF straight to disk next to your file.

ii

The workflow sections above still apply. Sheet sizes, grid, gutters, duplex, binding, transforms, barcodes and presets all work the way they are documented for Figma. What follows is only what differs: installing it, how it reads a selection, and what comes out the other end.

01

Version

3.4.0, matching the Figma build the interface was copied from.

02

Host apps

Adobe Illustrator only. The panel appears under Window → Extensions.

03

Biggest gain

Real PDF output. No temporary page, no manual export step.

19Illustrator — install the panel

An installer script does everything. You do not need administrator rights, Node.js, or any Adobe developer tooling — the panel ships prebuilt.

Install into Illustrator

  1. Quit Adobe Illustrator completely.

    Not just close the document — quit the application. If it is still running, the panel will not appear and you will conclude the install failed when it did not.

  2. Open the plugin folder in File Explorer.
    D:\Documents\Plugins\Impose Pro 3 - Illustrator
  3. Run install.ps1.

    The simple way: right-click install.ps1 → Run with PowerShell.

    If Windows blocks it, open PowerShell in that folder and run:

    powershell
    powershell -ExecutionPolicy Bypass -File install.ps1
  4. Let it finish. It does three things.

    a. Enables PlayerDebugMode — Illustrator refuses to load unsigned extensions without it. This is a per-user registry value, not a system change.

    b. Copies the panel to %APPDATA%\Adobe\CEP\extensions\ImposePro.

    c. Installs the Libre Barcode 39 font, which the barcode feature needs in order to render.

  5. Start Illustrator again.

    A full fresh launch, so it re-reads the extensions folder.

  6. Open the panel: Window → Extensions → Impose Pro.

    Dock it wherever you like — Illustrator remembers the position.

Window → Extensions → Impose Pro

20Illustrator — when the panel does not appear

If the panel is not in the Extensions menu, check these in order — they are the causes in descending order of likelihood.

CheckHow
Illustrator was actually restarted Quit it entirely and relaunch. Reopening a document is not a restart.
The files landed Paste %APPDATA%\Adobe\CEP\extensions\ImposePro into File Explorer’s address bar. You should see CSXS, index.html, host and lib.
PlayerDebugMode is set The installer sets it. If the folder exists but the panel does not appear, the version key may not match your Illustrator build — see the note below.
The script ran at all Re-run it from a PowerShell window rather than by right-clicking, so you can read any error message instead of watching the window vanish.
!

PlayerDebugMode and CSXS versions. The flag is a registry value under HKEY_CURRENT_USER\Software\Adobe\CSXS.nn, where nn is the CEP version your Illustrator uses. Different Illustrator releases use different numbers. If the panel will not appear, set a String value PlayerDebugMode = 1 under CSXS.10, CSXS.11 and CSXS.12 — harmless extras, and one of them will be the right one.

21Illustrator — sending it to coworkers

Do not zip the folder by hand — there is a packaging script that assembles a distributable bundle with the installer and a plain-language readme inside.

Build a shareable package

  1. Run the packaging script from the plugin folder:
    powershell
    powershell -ExecutionPolicy Bypass -File package.ps1
  2. Find the result in dist\.

    It writes dist\ImposePro-Illustrator-3.4.0.zip, containing the panel, install.ps1, the documentation and a plain-text READ ME FIRST.txt. The version number comes from manifest.xml, so it always matches the build.

  3. Send the zip. They unzip it and run install.ps1.

    They need no admin rights, no Node.js and no Adobe tooling. index.html ships prebuilt.

i

package.ps1 re-runs build.js first when Node is available, so you cannot accidentally ship a stale interface.

22Illustrator — signed .zxp distribution

For a wide rollout, a signed .zxp installs through Adobe’s Creative Cloud tooling and does not require PlayerDebugMode on each machine. It needs Adobe’s ZXPSignCmd binary and a certificate — self-signed is acceptable.

shell
ZXPSignCmd -selfSignedCert US CA "Your Company" "Impose Pro" <password> cert.p12
ZXPSignCmd -sign dist\_staging\ImposePro ImposePro.zxp cert.p12 <password>

The zip route is the default deliberately: it has zero external dependencies. Reach for .zxp only when you are deploying to many machines.

23Illustrator — using it

The workflow mirrors the Figma version, with one substitution: artboards are your pages.

  1. Open the Illustrator document whose artboards are the pages you want imposed.
  2. Open the panel — Window → Extensions → Impose Pro.
  3. Select one object on each artboard you want to include.

    A marquee drag across several pages works. Or select nothing at all to load every artboard in the document. See below for why it works this way.

  4. Click Load Selected Artboards.

    Pages load in artboard order, with thumbnails.

  5. Configure the job.

    Sheet size, grid, gutters, duplex, binding, templates, barcode, rotation and shift — all exactly as documented in the Figma guide. The interface is the same file.

  6. Click Impose.

24Illustrator — how selection picks artboards

You may expect to select artboards with the Artboard Tool (Shift+O). That does not work here, and the reason is a genuine Illustrator limitation: its scripting interface exposes no way to read a multi-artboard selection — only which single artboard is active. Selecting objects is the readable equivalent.

25Illustrator — what you get out

Two things, from one click:

01

A new Illustrator document

One artboard per imposed sheet. Vector stays vector unless you asked for flattening. Copies are expanded into real artboards during imposition, so they become genuine PDF pages.

02

A press-ready PDF

Written straight to disk next to your source file — or to the Desktop if that file has never been saved. Named <yourfile>_imposed.pdf, auto-numbered if one already exists.

i

This is the main practical gain over the Figma version. There, imposing built a page you then had to hand-export. Here the PDF is simply written for you.

Sheet backgrounds are CMYK 0/0/0/0 — no ink — rather than the opaque white the Figma version drew. That is correct for print: you do not want white ink laid onto white stock.

26Illustrator — excluding artwork

Registration marks, internal notes, a slug with the job number — things you want in the source file but never on the imposed sheet.

If the name containsEffect
<<Exclude>> That layer, item or artboard is ignored completely — absent from thumbnails, previews and printed output.

Rename the layer or object in the Layers panel to include <<Exclude>> anywhere in its name. Case as written.

27Illustrator — flatten modes

OptionResultUse when
Vector – keep editable Stays vector throughout. Default. Sharpest output, smallest file.
Flattened PNG – standard Rasterised at 300 ppi. Transparency or blend modes are causing trouble downstream.
Flattened PNG – HD Rasterised at hdScale × 150 ppi — so 150 to 600 ppi. You need flattening and higher resolution than 300.

28Illustrator — presets and templates

Unlike the Figma version, presets here are ordinary files on disk — which makes them easy to share across a print shop.

Documents\Impose Pro\presets.json  ·  Documents\Impose Pro\templates.json

Copy those files to another machine’s Documents\Impose Pro\ folder and that installation gets the same presets. There are also ready-made examples in the plugin folder under Presets\, including a 19×13 sheet size and door-hanger templates.

29Illustrator — check these on your first real job

✕

This port has not been run inside Illustrator. All of its code parses cleanly and the geometry is derived mathematically rather than guessed, but nobody has yet validated a printed sheet from it. Treat your first run as a shakedown: proof it against a known-good sheet before committing a production run to it.

  1. Rotation direction.

    Impose one cell at 90°. If it comes out mirrored about the horizontal axis, set ROTATION_SIGN = -1 in host/impose.jsx.

  2. Template mode orientation.

    Run a template whose orientation differs from the sheet. If it lands 180° off, negate TEMPLATE_ROTATION_DEG.

  3. Trim registration.

    Impose a 2×2 grid with zero gutters and physically measure the cut lines. They should be exact.

  4. Linked images.

    Art placed as a link rather than embedded may not survive being duplicated across documents. Embed linked images, or check the PDF carefully.

  5. Blend modes and effects when flattening.

    Illustrator’s rasteriser handles these well, but confirm on a job that uses transparency.

Debugging

With PlayerDebugMode on, open http://localhost:8088 in Chrome while the panel is running for a full DevTools console. Every message from the Illustrator side is logged with the prefix [Impose Pro host], and per-cell problems — unresolvable artwork, empty artboards, failed copies — are reported there rather than failing silently.

30Illustrator — tunables

At the top of host/impose.jsx. Edit only with a reason, and restart the panel afterwards.

ConstantDefaultPurpose
CLIP_TO_TRIMtrue Clips each page to its artboard. Turn off only if you want bleed to spill into the gutters.
ROTATION_SIGN1 Flip to -1 if rotations come out mirrored.
TEMPLATE_ROTATION_DEG90 Flip the sign if template mode lands 180° off.
BITMAP_PPI300 Standard flatten resolution.
BITMAP_HD_PPI_PER_X150 HD flatten: multiplied by the 1–4× setting in the panel.

31Illustrator — known limitations

  • Locked and hidden layers are skipped. Artwork must be visible and unlocked to be collected.
  • Groups are atomic. A group is placed as one unit; the collector does not descend into it looking for separate pages.
  • 1000 artboards maximum per document — an Illustrator limit, not this plugin’s. Sheets × copies × sides beyond that is rejected up front, with the actual number, rather than failing halfway.
  • The [Press Quality] PDF preset name is localised. On a non-English Illustrator the preset silently falls back to defaults; the log says so. Set exportSettings.pdfPreset if you need a specific one.
  • CEP is on Adobe’s long-term deprecation path. It works in Illustrator 2026 and there is no announced removal date, but a UXP rewrite will eventually be needed — and that means rebuilding the interface, not just the backend.
i

Why CEP and not UXP? UXP is Adobe’s modern platform, but its DOM is a restricted subset — this interface uses localStorage, fixed positioning, backdrop-filter, CSS grid and innerHTML rendering in dozens of places, so porting means rewriting all 4,300 lines of it. Illustrator’s UXP API is also still incomplete around artboards, rasterising and PDF output — precisely what this plugin needs. CEP runs a full Chromium panel, so the interface ports for free.

32Illustrator — when something goes wrong

SymptomCause and fix
Panel not in Window → Extensions Illustrator was not fully restarted, or PlayerDebugMode is not set for your CEP version. Work through Verifying it installed.
Panel opens but stays blank The interface failed to load. Open localhost:8088 in Chrome and read the console.
No artboards load Nothing was selected and the document has no artboards the collector can use, or everything is locked, hidden or marked <<Exclude>>.
