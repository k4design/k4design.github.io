Capabilities

Built for design-to-video handoff

🎞

Frames → timeline

Every selected frame becomes a segment. Set a hold time per frame, add crossfades, and export the whole sequence as one H.264 MP4.

🔊

Real video, real audio

Video fills inside your frames play back for their full duration — positioned, masked, and corner-rounded exactly as designed, with sound carried through.

🔒

100% local

Encoding runs in WebAssembly inside the plugin. The manifest declares zero network access — nothing ever leaves your machine.

Setup

Install in under a minute

01

Unzip the plugin

Extract frame-to-mp4-plugin.zip anywhere permanent — Figma loads the plugin from this folder every launch, so don't delete it.

02

Open the Figma desktop app

Development plugins can only be imported in the desktop app, not the browser.

03

Import the manifest

Go to Plugins → Development → Import plugin from manifest… and select manifest.json from the unzipped folder.

04

Launch

Run it any time from Plugins → Development → Frame to MP4.

Workflow

Select. Configure. Export.

01

Select frames on the canvas

Pick the frames you want — or select nothing to include every frame on the page. Order follows the canvas: top to bottom, left to right.

02

Review the frame list

Each frame appears as a row in the plugin. Untick to exclude, and set a hold duration for static frames (default 3s).

03

Attach source files to video frames

Frames with a video fill are flagged — attach the original video file and the badge turns green. Details below.

04

Export MP4

Pick fps, resolution, and crossfade, then hit export. A progress bar tracks the encode and figma-export.mp4 downloads when done.

Why the plugin asks for the source file

Figma's plugin API can't read video bytes back out of a design — so when a frame contains a video fill, attach the same file you originally placed in Figma. The badge flips from amber to green once it's loaded.

  • The frame plays for the full video duration — hold time doesn't apply
  • Position, size, rounded corners, and Fill/Fit scale mode are respected
  • Layers above and below the video stay layered correctly
  • MP4, MOV, and WebM sources supported · audio carried into the export
  • One playing video per frame; extras render as stills
Configuration

Three knobs. Sane defaults.

SettingOptionsGuidance
Frame rate 24 · 30 · 60 fps 30 fps suits most work. 24 for a filmic feel, 60 for extra-smooth motion.
Resolution 1× · 2× · 3× Multiplies frame size. A 1920×1080 frame at 1× is already full HD; 2× is a good default for crisp type.
Crossfade 0 · 0.3 · 0.5 · 1.0 s Dissolve between segments instead of hard cuts.
📐 Sizing: output dimensions come from the first frame in the list. Differently-sized frames are letterboxed — keep all frames the same size for best results.
⏱ Encode time: everything renders locally, frame by frame. Long videos or 3× resolution can take a few minutes — 3× pushes 9× the pixels of 1×.
Troubleshooting

When something looks off

The frame list is empty

Make sure you're on the page that has your frames, then hit Refresh frames. Only top-level frames are listed — groups and components aren't included.

"…has a video layer — choose its source file first"

A frame with an amber 🎬 badge doesn't have its source video attached yet. Click Choose video file on that row and select the same file you placed into Figma — or untick the frame to skip it.

The exported video has no sound

Audio comes only from the source video files — static frames are silent by design. If your source has audio but the export doesn't, the audio codec may not be MP4-compatible (rare with MP4/MOV, more common with WebM). Converting the source to MP4/AAC fixes it.

The video looks cropped, or has bars inside its box

The plugin follows the fill's scale mode from Figma: Fill crops to cover the box, Fit letterboxes inside it. Change the scale mode in Figma and re-export.

Export is slow

Drop to 1× or 2× resolution and 30 fps. Resolution dominates encode time.

Can it capture Smart Animate or prototype transitions?

No — Figma doesn't expose prototype playback to plugins. Use crossfades for motion between frames.
