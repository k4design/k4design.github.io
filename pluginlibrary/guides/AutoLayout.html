01Overview

This plugin turns an existing Figma design — a flyer, a postcard, a listing sheet — into a reusable template. You tag each text layer and photo container once. After that, producing the next property means typing the details, dropping in the photo shoot, and clicking Apply.

Tagging changes nothing visually. Tags are invisible metadata stored on the layers, so a tagged template still looks and exports exactly as designed.

01

Stored in the file

Tags, entered content and uploaded photos all live in the Figma document. Duplicate the file and the whole setup travels with it.

02

Fully offline

No account, no server, no API key. The plugin makes zero network requests — nothing leaves your machine.

03

One undo per apply

Every apply collapses into a single history step, so ⌘Z always puts things back.

03Quick start

  1. Tag the template

    Select a text layer, pick a field under Content (text) on the Tag tab, hit Assign. Same for photo containers under Photos (image). If your layers are already named sensibly, jump to Scan layer names on the Bulk tab and let it do the work.

  2. Enter the listing

    Fill in the grouped fields on Content — stats, address, copy, features, agent. Values save into the file as you type, or import a CSV.

  3. Load the photos

    Drop the whole shoot onto the upload area on Photos. Images fill the numbered slots in filename order; reorder with the hover arrows.

  4. Apply

    Use the button pinned to the bottom of Content and Photos, or open Apply to check the file first and push everything in one pass.

✓

Every apply is a single undo. If something lands wrong, one ⌘Z / Ctrl+Z reverts it. Apply everything counts as two — one for content, one for photos.

04Tagging

Tagging by hand

Select one or more layers. The Tag tab lists what's selected along with any tag each layer already carries. Choose a field from the matching dropdown and press Assign — it applies to the whole selection at once. Remove tag clears them.

The dropdowns annotate themselves: ×3 means three layers already carry that field, and • photo marks a slot that has an image loaded.

Tagging from layer names

Scan layer names on the Bulk tab recognises three patterns:

Layer nameBecomes
#anythingThe # is stripped and the rest becomes the field. Text layers get a content tag, everything else a photo tag.
price, street, headlineA text layer named exactly like a field gets that content tag.
img:3, img:logoA layer named exactly like a photo slot gets that photo tag.

The scan never overwrites an existing tag, so it's safe to re-run after adding layers. Anything it doesn't recognise is left completely alone.

Locking layers against changes

Some layers must never change — a legal disclaimer, a logo baked into the design, decorative artwork. Tag those with a reserved field and every apply skips them.

FieldShown asEffect
text.locked“Never overwrite”Text is never rewritten
photo.locked“Never replace”Image fill is never replaced

Tagging part of a text layer

When only a few words in a sentence are dynamic, select a single text layer — a Partial text (template) box appears, pre-filled with the layer's current words. Wrap the dynamic parts in double braces:

template 
Offered at {{price}} · {{bedrooms}} bed / {{bathrooms}} bath

Everything outside the braces is preserved exactly; each token is swapped for its value on apply. One layer can pull in as many fields as you like.

The tag index

Below the selection card is every tag in use, with how many layers carry it. Click a row to select those layers on the canvas — the fastest way to find out what a tag actually points at.

Rebuild index re-reads the page from scratch. You rarely need it, but it's the fix when counts look stale, and it's what teaches the plugin about tags inside component instances.

Seeing your tags on the layout

Tag overview renders the selected frame — or the largest one on the page — and draws a box over every tagged layer: violet for content, green for photos. Click a chip below the preview to isolate a single tag. Quickest way to spot a container you forgot.

↑

Upgrading from an older version? Tags written by earlier releases are converted automatically the first time the plugin reads them — including partial-text ranges, which become templates. Nothing to re-tag.

05Content

A grouped form: Stats, Address, Copy, Features, Agent. It saves as you type, with Apply all content pinned to the bottom.

Each label carries a live count of how many layers use that tag — or a grey not tagged when nothing on the page will pick the value up. 1 tpl means the field is referenced by a template rather than tagged directly.

Two fields are composed for you

FieldOutput
statsCombo Beds, baths and square footage on one line — 4 Bedrooms  |  3 Bathrooms  |  3200 sq/ft. Ideal for a stat bar.
featuresBulleted Features 1–6 stacked on separate lines in a single text layer, so a bullet list is one tagged layer instead of six.

You never type these — they're assembled from the fields you already filled in. Just tag a layer with them. price is formatted automatically too, so 1250000 places $1,250,000.

CSV

Download CSV exports the current values as a single-row sheet; Import CSV reads one back. Column order doesn't matter and unknown columns are ignored, so it's fine to keep extra notes alongside. The easy path when listing data comes out of another system.

06Photos

Uploading

Drop the whole shoot onto the upload area, or click to browse. Photos sort naturally by filename — IMG_2 before IMG_10 — and fill the empty slots in order. You can also drop a single file straight onto one slot to replace just that image.

A slot's position is its tag

The first slot is img:1, the second img:2, and so on. Hover a thumbnail for arrows to move it earlier or later, or × to clear it. The badge turns green once at least one layer on the page is tagged with that slot.

Slots 1–3 are healthy. Slot 4 is tagged but empty, so a container on the page will come out unfilled. Slot 5 is the reverse — a photo nothing points at yet. Slot 6 is unused.

Logo and custom slots

The logo has a dedicated slot using img:logo. For anything outside the numbered run — a brochure cover, a site plan — add a custom image tag such as img:brochure and it gets its own upload slot.

Readiness list

At the bottom, every photo tag that exists on the page is marked ready or empty with a layer count. Click a row to select those layers. Scan it before applying to catch a slot with no photo.

!

Don't delete the 🗄 Image vault rectangle. Full-resolution images are handed to Figma once and stored in the document; the panel keeps only a thumbnail. That invisible locked rectangle is what stops Figma garbage-collecting photos you've uploaded but not yet applied.

Anything above Figma's 4096px limit is scaled down on the way in, and formats Figma can't read (WebP, AVIF) are converted to JPEG. A photo that already fits is passed through untouched, so print quality is preserved.

07Apply

You can apply straight from the pinned buttons on Content and Photos. The Apply tab is for looking before you leap.

CHECK

File check

Re-reads the document and reports anything that would make an apply incomplete: slots with no photo, tagged fields with no value, values no layer will pick up. Also heals tags left by deleted layers.

PREVIEW

Dry run

Counts exactly how many layers would change and lists every field as ready or empty. Writes nothing.

RUN

Apply

Everything at once, content only, photos only, or a single field group. Long runs show progress with a Cancel button.

Each problem in the file check lists its fields as chips — click one to jump straight to those layers. Cancelling an apply stops cleanly and reports how far it got.

08Bulk

One-click passes over the whole template, plus save state.

Scan layer names

Tags layers from their names — see Tagging. Safe to re-run; existing tags are never touched.

Rename layers to tags

The reverse: renames every tagged layer to the tag it carries, so the layer list mirrors the tagging. Makes a template far easier to hand off. Layers inside component instances take their name from the main component, so those are skipped.

Read back from canvas

Pulls the current words out of tagged text layers into the form and adopts photos already sitting in tagged containers. Use it when someone hands you a filled-in file. Canvas values win over what's typed in the panel, so it's an overwrite — ⌘Z if that wasn't the intent.

Save state

Download save state produces a zip you can archive or hand to a colleague:

EntryContents
data.csvEvery field value
assignments.csvWhich photo sits in which slot
tags.jsonEvery layer tag on the page
images/Every uploaded photo, full resolution

Upload save state restores all four. Photos land back in their original slots and tags re-apply immediately; nothing else on the canvas changes until you Apply.

10Troubleshooting

I clicked Apply and nothing happened

Almost always nothing is tagged yet. Check the tag index on the Tag tab — if it's empty, tag some layers or run Scan layer names.

If the index looks right, run Dry run on the Apply tab to see which fields are actually considered ready.

A photo slot came out empty or magenta

A layer is tagged with a slot that has no photo in it. The readiness list on the Photos tab and File check on the Apply tab both point these out.

“Its photo is missing from Figma's storage”

The image was garbage-collected — usually because the 🗄 Image vault rectangle was deleted. Re-upload the photo on the Photos tab and it re-links.

A text layer didn't update

Check whether it's tagged text.locked, or whether it lives inside a component instance. Instances inherit tags from the main component — run Rebuild index once so the plugin knows about them.

The layer counts look wrong

Rebuild index on the Tag tab re-reads the page from scratch.

I tagged the wrong thing

Select the layers and hit Remove tag. To start over, Clear all tags strips every tag on the page — entered content and uploaded photos are kept. Both are undoable.
