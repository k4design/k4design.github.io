01How it works

Three things have to line up:

  1. A frame containing a number of component instances — each instance is one “row slot”. Six instances means six rows fit per page.
  2. A CSV file whose first line is column headers and whose remaining lines are the data.
  3. A mapping you set up in the plugin: this CSV column goes into the text layer with this name.

02Preparing your design

This is the part people get wrong, so do it first and do it carefully. The plugin only fills component instances, and it finds text inside them by layer name.

  1. Build one row as a component.

    Design a single card / row / listing block. Select it and press Ctrl+Alt+K (Windows) to make it a component. You will see a purple diamond icon on it in the Layers panel.

  2. Name the text layers inside it.

    In the Layers panel, double-click each text layer’s name and rename it to something short and meaningful: name, price, beds. These names are what you will map columns onto.

    The layer name is not the visible text. Figma names a new text layer after whatever you typed in it, which is why an unrenamed layer showing “$425,000” is literally named $425,000 — useless as a mapping target. Rename them.

  3. Place instances of that component into a page frame.

    Drag the component from the Assets panel into your page layout as many times as you want rows per page. Six instances = six rows per page. Every one of them must be an instance of the component, not a copy-pasted group.

  4. Confirm the instance count.

    That number is your page capacity. It decides how many pages get created — see How extra pages are made.

03Preparing your CSV

The CSV reader here is deliberately simple. Keep the file simple and it will never surprise you.

01

Required

First line = column headers. Every following line = one row of data. Commas separate the values. Save as .csv, not .xlsx — in Excel or Google Sheets use Save as / Download as → CSV.

02

Avoid

Commas inside a value, even in quotes — "Smith, John" will split into two columns and shift everything after it. Also avoid blank header cells and merged cells.

A good CSV looks like this

text
name,price,beds,baths
Elm St,425000,3,2
Oak Ave,510000,4,3
Pine Rd,389000,2,1
!

Instead of "Smith, John" use Smith - John, or split it into two columns (last, first) and map both. Prices are safer without thousands separators — write 425000, or pre-format them as 425k / $425K in the spreadsheet.

04Install

CSV Importer is published on the Figma Community, so no files from this computer are needed.

Recommended — install from the Community

  1. Open Figma — desktop app or browser.
  2. Go to the Community and search “CSV Importer”.

    Click the Figma logo top-left → Community in the sidebar → type CSV Importer. Filter to Plugins if needed.

  3. Open the plugin page and save/run it.

    It attaches to your Figma account, so it is available in every file you open on any computer you log into.

i

Testing a local build instead? In the Figma desktop app only: Plugins → Development → Import plugin from manifest… and choose:

D:\Documents\Plugins\CVS Importer2\manifest.json

Use CVS Importer2. CVS Importer1 is the older iteration.

Opening it

Plugins → CSV Importer

The panel opens with four numbered sections. Work top to bottom.

051 · Load Selected Frame

  1. Click anything inside your page frame on the canvas.

    You can click the frame itself, or any layer inside it — the plugin walks upwards to find the top-level frame either way.

  2. Click Load Selected Frame.
  3. Confirm what it found.

    The panel shows the frame name and a list of every text layer name inside it. If the list is full of things like $425,000 and Lorem ipsum, your text layers are unnamed — go back and rename them, then load again.

062 · Upload CSV

  1. Click the file button in section 2 and pick your .csv.
  2. Check the column count and row count it reports.

    If the column count is higher than you expect, you have a stray comma inside a value. If the row count is one lower than your spreadsheet, that is correct — the header line is not a data row.

i

The file is read inside Figma on your machine. The plugin has no network access at all, so nothing is uploaded anywhere.

073 · Map columns

A mapping is one line saying “take column X, put it in the text layer named Y”. You need one per field you want filled.

  1. Click + Add Mapping.

    A new row appears with two dropdowns.

  2. Left dropdown: pick the CSV column.

    These come from your header row.

  3. Right dropdown: pick the text layer name.

    These come from your frame. Names match exactly, including capitals — Price and price are different layers.

  4. Repeat for every field.

    Columns you do not map are simply ignored, which is fine — a spreadsheet can carry extra data you do not put on the page.

!

A mapping that points at a layer name that does not exist is skipped silently. If one field stays as placeholder text after populating, this is almost always why: a typo in the layer name, or the name changed after you loaded the frame. Fix the name, click Load Selected Frame again, and remap.

084 · Populate

  1. Click Populate Design.
  2. Watch the progress readout.

    It counts rows as it places them. Large files take a moment — the plugin has to load each text layer’s font before it can change the words.

  3. Check the result on the canvas.

    Your original frame is filled with the first batch of rows, and additional pages sit below it holding the rest.

✕

Populate changes your frame in place — it does not work on a copy. Duplicate the page first (right-click the page name → Duplicate page) if you want the clean template kept. There is no undo button in the plugin; Ctrl+Z on the canvas is your only fallback.

Six instances of one component, before and after a Populate run. Rows 7 onward land on duplicated pages below.

09How extra pages are made

Capacity is the number of instances in your frame. Rows ÷ capacity, rounded up, is how many pages you get.

i

This is a toggle, not a law. The Options block carries Delete unused components — on by default. Leave it on and a 4-row CSV into a 6-slot frame deletes the two spare instances permanently; turn it off and they stay, still showing placeholder text. Auto-duplicate frame for overflow controls the extra pages, and Continue from previous population resumes where the last run stopped instead of starting over. Either way, work on a duplicate of the template.

10When something goes wrong

SymptomCause and fix
Nothing happens when you click Load Selected Frame Nothing was selected, or the selection is not inside a frame. Click a layer inside your page frame first. Loose layers sitting directly on the canvas have no parent frame to find.
Loaded fine, but Populate does nothing Your frame contains no component instances. The plugin only fills instances — copy-pasted duplicates do not count. Turn one row into a component and place instances of it.
One field never updates The mapped layer name does not exist inside the instance. Check spelling and capitals in the Layers panel, reload the frame, remap.
Values land in the wrong columns A comma inside one of your CSV values split it into two. Open the CSV in a plain text editor and look for it. Remove the comma or split the column in two.
Only some rows appear They will be on the duplicated pages below the original — scroll down, or press Shift+1 to zoom to fit everything.
Instances vanished from the template Expected behaviour: unused slots are deleted on the last page. Undo with Ctrl+Z, then work on a duplicated page next time.
Fonts look wrong or text refuses to change The font is not available to Figma. Install it locally (and the Figma font helper for the desktop app), or restyle the text layer to a font you have.
