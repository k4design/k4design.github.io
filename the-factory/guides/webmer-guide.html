01 · What it is

What it does

Webmer is a Mac app that wraps ffmpeg in a queue and a settings panel. You drop video files on it, pick a format and a preset, and it writes the converted file next to the original. It runs entirely on your machine — nothing uploads anywhere.

The point of it is the two things a command line makes tedious: batching — a queue of files each with their own settings — and knowing the size before you wait. Webmer encodes a three-second sample from the middle of each file with your real settings and extrapolates, so the queue shows an estimate per file before you press Convert.

01

Nothing to install

A static ffmpeg ships inside the app bundle. No Homebrew, no PATH, no version drift.

02

Size before you commit

A short sample encode with your exact settings, extrapolated to full duration. Re-runs when you move a slider.

03

Per-file settings

Every queued file carries its own settings. Set one up the way you want, then push it to the rest.

02 · Install

Install

Webmer ships as a DMG. It is signed but not notarized, so macOS will stop you the first time and only the first time.

  1. Open the DMG

    Drag Webmer onto the Applications shortcut in the disk image.

  2. First launch — right-click, Open

    In Applications, right-click (or Control-click) Webmer and choose Open, then click Open again in the dialog. Double-clicking the first time will just be refused.

  3. If that doesn't work

    Open System Settings → Privacy & Security, scroll down, and click Open Anyway next to the Webmer message. Launch it again.

  4. Done

    After that it opens normally, like any other app.

i

Why the warning? Notarization means uploading the app to Apple for scanning and stapling their ticket to it. Webmer is signed with a Developer ID but that step hasn't been run, so Gatekeeper asks once. Nothing about the app changes after you allow it.

03 · The window

The interface

One window, split down the middle. The divider drags — the settings pane sits between 260 and 320 points wide.

Left · Settings

With nothing selected this is Default Settings — what new files inherit as you add them. These persist between launches.

Select a queued file and the same panel becomes File Settings for that one file, with its name underneath the title. Changes apply to that file only, until you press Apply to All Queued Files.

Right · Queue

Empty, it is a drop zone. Populated, it is a list — one row per file showing its format, its size estimate, and its state.

Along the bottom: Add Files…, Clear Finished when there is anything finished to clear, and Convert on the right. Convert is the default button, so Return presses it.

Files convert one at a time, in queue order. That is deliberate — video encoding already saturates the cores, and running four at once mostly makes all four slower.

04 · Formats

The four outputs

Pick by what the destination needs. The two WebM codecs carry audio; the two image formats do not.

FormatCodecAudioAlphaReach for it when
WebM · VP9libvpx-vp9 Yes · OpusYes The default. Broad browser support, and the only format here that does transparency and sound.
WebM · AV1libsvtav1 Yes · OpusNo Smaller files than VP9 at the same quality. Slower to encode, and no alpha.
GIFpalettegen + paletteuse NoYes Somewhere that still insists on GIF. Two-pass palette, so it looks far better than a naive export.
Animated WebPlibwebp NoYes A GIF replacement — much smaller, still animated, still transparent.
!

AV1 has no alpha. Choose the Transparent preset with AV1 selected and the panel says so in orange. Switch to WebM · VP9 or Animated WebP to keep transparency.

What it will accept

Dropped files are filtered by extension — anything else is silently ignored rather than queued and failed:

accepted extensions
mp4   mov   m4v   avi   mkv   webm   mxf
mts   m2ts  wmv   flv   gif   mpg    mpeg

GIF is on both lists on purpose — a GIF in, a WebM or WebP out, is one of the more useful things this does.

05 · Presets

Presets

A preset writes several values at once. Pick one first, then open Advanced only if you need to argue with it. These are the actual numbers each one sets:

PresetQuality (CRF)SpeedAlphaAudio

High Quality221 — slowestOffOn · 160 kbps

Transparent (Alpha)282OnOff
i

CRF is inverted. Lower means better quality and a bigger file. 22 is close to visually lossless for most footage; 42 is where you accept visible artefacts in exchange for a small file.

06 · Convert

Running a batch

  1. Set the defaults first

    With nothing selected, the left pane is Default Settings. Whatever is set here is what files inherit as they are added — so set it before you drop, not after.

  2. Drop the files in

    Drag onto the right pane, or Add Files…. A dashed accent border confirms the drop target. Each file lands as its own row.

  3. Wait for the estimates

    Each row says estimating size… then settles on a figure. If you change a setting, estimates re-run — but only after you stop moving the slider for 0.7 seconds, so a drag doesn't spawn an encode per tick.

  4. Adjust individual files

    Click a row to edit just that file. Happy with it? Apply to All Queued Files copies those settings across every other queued row.

  5. Convert

    Press Convert (or Return). Files run one at a time. Anything added during a run waits for the next press — the queue only arms what was waiting when you pressed.

Where the output goes

Next to the source file, same name, new extension. Existing files are never overwritten — a second pass produces clip-2.webm, then clip-3.webm, and so on.

output naming
# first run
~/Movies/reel.mov   →   ~/Movies/reel.webm

# run it again without moving the first one
~/Movies/reel.mov   →   ~/Movies/reel-2.webm

How the estimate is made

It is a real encode, not a guess from a bitrate table. Webmer takes a three-second slice from the middle of the source, encodes it with the exact settings you have chosen, measures the bytes, and scales that up to the full duration.

i

That makes it accurate for footage with an even complexity, and optimistic or pessimistic where the middle isn't representative — a title card in the middle of an action sequence will under-estimate. Treat it as a close guide, not a contract.

08 · Troubleshooting

When it misbehaves

"ffmpeg binary not found"

The bundled binary is missing from the app — usually because the app was rebuilt without running fetch-ffmpeg.sh first. A Homebrew ffmpeg at /opt/homebrew/bin or /usr/local/bin is used as a fallback if one is there.

The size estimate never appears

Shown as size unknown. It means the sample encode failed or the duration couldn't be read — most often a source with a broken or missing duration header. Conversion itself may still work.

Transparency came out black

Check the format. AV1 cannot carry alpha, and Preserve transparency has to be on — the Transparent preset switches it on for you, other presets switch it off.

A file failed

The row shows the last few lines of ffmpeg's own error output. A part-written output file is deleted rather than left behind as a broken artefact.

Dropped files didn't appear

The extension isn't on the accepted list. Rename to the real container extension, or convert it to something on the list first.

Convert is greyed out

Nothing is waiting, or a run is already going. Files added mid-run stay queued until the current batch finishes and you press it again.

09 · Build

Building from source

A Swift package — SwiftUI front end, ffmpeg doing the work. Three scripts, in order:

webm — build
# 1. fetch the static arm64 ffmpeg into Resources/
./fetch-ffmpeg.sh

# 2. release build, assemble Webmer.app, sign it
./build-app.sh

# 3. wrap it in a DMG with the install instructions
./make-dmg.sh

build-app.sh picks the best signing identity it can find — Developer ID first, then Apple Development, falling back to ad-hoc — and signs the bundled ffmpeg before the app, with the hardened runtime on, which is what notarization would need if you ever run it.

10 · Limits

Known limits

Apple Silicon only

Both the app and the bundled ffmpeg are arm64. There is no Intel build.

macOS 14 or newer

Set in the package manifest and enforced by the bundle.

Not notarized

Signed, but Gatekeeper still asks once on first launch. See Install.

One file at a time

The queue is serial by design. No parallel encoding setting.

Output location is fixed

Always beside the source. No output-folder picker.

No trimming or cropping

Format, quality, resolution and frame rate only. Cut before you convert.
