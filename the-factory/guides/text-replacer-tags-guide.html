01The core idea

Everything hinges on one convention: a layer whose name starts with an asterisk is a layer the plugin manages.

Name a text layer *Headline and it becomes a group called Headline in the plugin. Type new text into that group, press Apply, and every layer named *Headline on the page is rewritten.

i

The asterisk is in the layer name, not in the text. The layer name is what you see in the Layers panel down the left side of Figma. The text is what renders on the canvas. Renaming a layer never changes a single visible character — so the asterisk never appears in the design.

Why this survives

  • Group definitions are saved on the document itself, so closing Figma and coming back next week loses nothing.
  • Membership is worked out live from layer names. Duplicate a frame, and the new *Headline inside it is picked up automatically — nothing to re-add.
  • A deleted layer is dropped from its group by itself.

02Install

Not on the Figma Community — it installs from the folder on this computer. That means the Figma desktop app, and the folder must stay where it is.

Development install — do this once

  1. Open the Figma desktop app and open any design file.

    Browser Figma cannot import local plugins, and the import menu is unavailable on the file-browser screen.

  2. Plugins → Development → Import plugin from manifest…

    Via the Figma logo top-left, or right-click empty canvas → Plugins.

  3. Select manifest.json in the plugin folder.
    D:\Documents\Plugins\Text replacer - Tags\manifest.json
  4. Run it from Plugins → Development → Text Replacer + Tags.
i

There is a simpler sibling — the simpler build — with * groups and image groups but no tags. Both can be installed at once; they use different plugin IDs and do not collide.

03Setup: marking your layers

Do this once per file. Two ways in — the first is easier.

Option A — mark from the canvas (recommended)

  1. Select the layer or layers that change each week.

    Click the text layer on the canvas. To mark the same field across several frames at once, Shift-click each one — for example the headline in all four frames.

  2. Type a name in the Mark field in the plugin.

    Plain words, no asterisk — the plugin adds it. Headline, Date, Price.

  3. Click Mark.

    The selected layers are renamed to *Headline and the group appears in the panel. Text layers become text groups; image or shape layers become image groups.

  4. Repeat for each field you want to control.

Option B — name layers by hand, then sync

  1. Rename layers in the Layers panel yourself.

    Double-click the layer’s name and type *Headline. Keep the spelling identical everywhere it appears — *Headline and *headline are two different groups.

  2. Click ⟳ Sync groups from *layers.

    Every distinct marked name becomes a group, with the leading asterisk stripped from the label.

i

Sync is safe to press whenever. It rebuilds the group list from what is currently on the page — it never deletes layers.

04The weekly routine

Once marked, this is the whole job:

  1. Open the plugin.

    Your groups appear on their own — no reselecting, no re-marking.

  2. Optionally select the frames you want to limit changes to.

    See Scope below.

  3. Type the new text into each group’s box.
  4. Press Apply on that group — or Apply all text for everything at once.

    Every matching layer in scope is rewritten.

Per-group controls

ControlWhat it does
Click the group title Renames the match — that is, which *name this group looks for. It does not rename your layers, so change it only if you also renamed the layers.
Select on canvas Selects every layer this group currently matches. The fastest way to confirm a group is pointed at what you think it is.
Remove Deletes the group from the plugin only. Your layers and their names are untouched — a Sync would bring the group straight back.

One Apply pass: the two * groups and the tagged paragraph all update together, and no asterisk is ever visible in the design.

05Image groups

Exactly the same convention. Name an image or shape layer *Logo, sync or mark it, and it becomes an image group.

  1. Click Choose… in the image group and pick a PNG or JPG from your computer.
  2. Click Replace image.

    Every layer named *Logo in scope gets the new image, with its scale mode set to Fill.

i

A placeholder shape works too. A marked rectangle with a plain solid fill is swapped to an image fill on replacement — you do not need to place a dummy photo first.

Adjustments such as saturation, contrast and exposure are left alone deliberately. Set those in Figma after replacing, and they stick to the layer.

Image files are read locally in the panel. The plugin has no network access.

07Tags — changing part of a sentence

A * group replaces a whole text layer. Tags exist for when only part of a sentence changes, and the words around it differ from layer to layer.

You mark the changing part as a {{token}}. Everything around it stays literal. Each layer keeps its own sentence, so layers with completely different wording all update correctly from one value.

Creating a tag

  1. Select exactly one text layer on the canvas.

    One — not several. The Tag part of this text editor only appears for a single selected text layer.

  2. Find its text in the editor box inside the plugin.

    The layer’s text is copied into an editable box in the panel.

  3. Highlight the part that changes.

    Drag across it inside the plugin’s box, not on the canvas. Figma cannot tell a plugin what you have highlighted on the canvas — the plugin can only read its own box. That is why the text is duplicated here.

  4. Pick an existing tag from the list, or type a new tag name.

    Short and lowercase works well: guest, episode, price.

  5. Click Wrap selection.

    The highlighted part becomes {{guest}}. Everything else stays literal.

  6. Click Save template.

    This stores the template on that layer. Skip it and the layer will not update when the tag is applied.

  7. Repeat for every other layer that mentions the same thing.

    Each layer needs its own template, because each has its own surrounding sentence. A text layer can carry several tags at once — a sentence with both a guest and an episode number is fine.

Applying a tag

  1. Set the tag’s value — either its own Value field, or the * group it is linked to (see below).
  2. Click Apply on the tag, on its linked group, or use Apply all text.
  3. Every layer whose template uses that token is re-rendered.

    The replacement is a style-preserving diff: only the token’s span is rewritten, so bold runs, colour changes and mixed fonts elsewhere in the paragraph survive intact.

i

A token with no value yet stays visible as {{guest}} rather than blanking the sentence. If you see that on the canvas, the tag has no value — it is a reminder, not a bug.

08Linking tags to groups

Maintaining a value in two places is how values drift. Linking fixes that: point a tag at a * text group, and applying the group also updates every templated layer using the tag, in the same pass and the same scope.

  • Link by hand — pick the matching * group in the tag’s link control. Recommended: the value then lives in exactly one place.
  • Auto-link by name — one button links every unlinked tag to a group that shares its name (guest → *guest). Links you set by hand are never overwritten.

09Organizing groups and tags

Files with thirty groups get unwieldy. The panel has tools for that:

  • Search — filters both groups and tags as you type.
  • Group by — switch between nesting each tag under the * group it links to, or filing everything into manual folders you create yourself (folders can hold whole-layer groups too).
  • Collapse — every section folds away.
i

Deleting a folder never deletes its contents. They move to Unfiled.

10When something goes wrong

SymptomCause and fix
A group is missing after sync No layer on the current page carries that name. Check spelling and capitals in the Layers panel — *Headline ≠ *headline. Also confirm you are on the right page.
Apply changed some layers but not others The missed layers are named differently, or sat outside your selection. Use Select on canvas to see exactly what the group matches.
An asterisk is showing in the design You typed it into the text instead of the layer name. Remove it from the text; put it on the name in the Layers panel.
{{guest}} is visible on the canvas That tag has no value yet. Fill its Value field, or link it to a * group that has one, and apply.
A templated layer never updates Its template was not saved. Select that single layer, wrap the token again, and click Save template.
The tag editor will not appear It needs exactly one text layer selected. Zero, several, or a non-text layer all hide it.
Highlighting on the canvas does nothing Expected. Figma cannot pass a canvas text selection to a plugin. Highlight inside the plugin’s own text box.
Frames you did not want got updated Nothing was selected, so the whole current page was in scope. Select just the frames you want, or move archives to another page.
Text refuses to change The layer’s font is not available to Figma. Install the font, or restyle the layer to one you have.
Image replaced but framed wrongly Replacement always uses scale mode Fill. Adjust the crop on the layer in Figma afterwards.

11The Adobe edition

Everything above is the Figma plugin. The same idea is also available as a CEP panel for Adobe InDesign and Illustrator — one panel that serves both apps and detects which one it is running in.

!!

The tag mechanism is genuinely different, so do not skim this part. The Figma plugin stores a {{token}} template on each layer. The Adobe panel instead does a find and replace inside the item: you tell it the snippet as it reads right now and what to change it to. Same goal, different handling — and a stale find value silently matches nothing.

01

Host apps

InDesign and Illustrator. The panel appears under Window → Extensions.

02

What carries over

*Name whole-item groups, image replacement, and style-preserving text edits.

03

What changes

Tags are #tag# in the item name and work by find/replace, not stored templates.

12Adobe — how the two mechanisms differ

Everything is driven by item names — the name of a frame or object as shown in the Layers panel. Both InDesign and Illustrator let you name items individually, and that is what the panel reads.

01

*Name — whole-item groups

An item whose name starts with * is managed. A text item becomes a text group: you retype its entire text. An image or shape item becomes an image group: you replace the placed image, fitted to fill.

02

#tag# — snippet replacement

A text item whose name contains #tag# takes part in that tag. Applying the tag finds a snippet of text inside the paragraph and replaces just that, leaving the rest alone.

Groups and tags are discovered live from item names on every scan — there is no separate list to maintain.

13Adobe — install the panel

There is no installer script for this one. It is three manual steps, done once per computer. You do not need administrator rights.

Step 1 · Enable unsigned extensions — once per computer

On Windows:

  1. Press Win+R, type regedit, press Enter.

    Click Yes if Windows asks for permission.

  2. Navigate to:
    HKEY_CURRENT_USER\Software\Adobe\CSXS.11

    Paste that into the address bar at the top of the Registry Editor. If the key does not exist, right-click Adobe → New → Key and name it CSXS.11.

  3. Add a String value named PlayerDebugMode with the value 1.

    Right-click in the right-hand pane → New → String Value → name it PlayerDebugMode → double-click it → type 1 → OK. A String value, not DWORD.

  4. Repeat for CSXS.10 and CSXS.12.

    Different Adobe versions use different CEP numbers and there is no harm in setting all three. This is the single most common reason a panel never appears.

On macOS, run this in Terminal, once per version:

shell
defaults write com.adobe.CSXS.11 PlayerDebugMode 1
defaults write com.adobe.CSXS.10 PlayerDebugMode 1
defaults write com.adobe.CSXS.12 PlayerDebugMode 1

Step 2 · Copy the panel into place

  1. Quit InDesign and Illustrator completely.

    They read the extensions folder at launch and will not notice a panel added while running.

  2. Copy this whole folder:
    D:\Documents\Plugins\Text replacer - Adobe
  3. Paste it into the CEP extensions directory.

    Windows:

    C:\Users\<you>\AppData\Roaming\Adobe\CEP\extensions\

    macOS:

    ~/Library/Application Support/Adobe/CEP/extensions/

    On Windows, paste %APPDATA%\Adobe\CEP\extensions into File Explorer’s address bar to jump straight there. Create the CEP and extensions folders if they are missing.

  4. Check the result.

    You should end up with a folder inside extensions\ that directly contains CSXS, index.html, jsx and lib. A nested Text replacer - Adobe\Text replacer - Adobe\ is the classic copy-paste mistake — the panel will not load.

Step 3 · Open the panel

  1. Start InDesign or Illustrator.
  2. Window → Extensions → Text Replacer + Tags

    The same panel serves both applications and detects which one it is running in. Dock it wherever suits you.

Window → Extensions → Text Replacer + Tags

15Adobe — packaging as a signed .zxp

For a wider rollout, a signed .zxp installs normally and does not need PlayerDebugMode on each machine. You need Adobe’s ZXPSignCmd tool, from the Adobe CEP resources on GitHub.

Then from the plugin folder:

powershell
# creates a self-signed cert on first run and signs the folder into TextReplacer.zxp
build\package.ps1 -ZxpSignCmd "C:\path\to\ZXPSignCmd.exe"

Install the resulting .zxp with a ZXP installer — Anastasiy’s Extension Manager or ZXPInstaller. Self-signed packages install fine; they simply are not Adobe-certified, so the installer may say the publisher is unverified.

17Adobe — naming your items

Two conventions, both applied to the item’s name in the Layers panel — never to the visible text.

Name itBecomesExample
*Something A whole-item group. Text item → retype the whole text. Image or shape → replace the placed image. *Headline, *Date, *GuestPhoto
Name containing #something# Participation in that tag — the changing snippet inside a longer text. Intro #guest#, Caption #guest# #episode#

You can name items two ways:

  1. By hand in the Layers panel.

    Double-click the item’s name and type it. Then click ⟳ Rescan in the panel so it picks up the change.

  2. From the panel.

    Select the items on the page, then use the Mark field (for * groups) or the Tag field (for #tag#) and confirm. The panel renames them for you.

i

Rescan is always safe. It rebuilds the list from what is currently in the document and never changes your artwork.

18Adobe — using groups

  1. Click ⟳ Rescan if you renamed anything by hand.
  2. Text group — edit the box, click Apply.

    The item’s entire text is replaced. Every item sharing that *name is updated.

  3. Image group — click Replace image… and pick a file.

    The placed image is swapped and fitted to fill.

!

In Illustrator, images must be linked (placed) files. Embedded raster images cannot be relinked by script and are skipped — the panel reports how many it skipped. If a photo will not replace, that is why: place it as a link instead of embedding it.

19Adobe — using tags

A tag is for when only part of a text should change. Unlike the Figma version — which stores a {{token}} template on each layer — this version works by find and replace within the item:

  1. Set current text to find.

    The snippet as it reads in the document right now — for example Dana Okafor.

  2. Set replace with.

    The new snippet — Marisol Reyes. Alternatively, link the tag to a * box so the value is maintained in one place and pulled from there.

  3. Click Apply.

    Every text item whose name carries that tag has the snippet located and replaced inside its text. Everything around it is untouched and keeps its exact styling; the replacement inherits the styling the old snippet had.

!

The find value must match what is actually in the document. Because this is a find-based mechanism rather than a stored template, a tag whose find text is stale — you already replaced it last week — will match nothing and silently do nothing. After each apply, the new text is the next find value, so update it. Tag find and link values are remembered per document, so this is generally handled for you between sessions.

A text item can carry several tags: Caption #guest# #episode# takes part in both.

20Adobe — where settings are kept

Groups and tags themselves are not stored anywhere — they are re-derived from item names on every scan, so they cannot fall out of sync with the document.

Tag find and link values are remembered, per document, in a small JSON file inside your user-data folder. Two consequences worth knowing:

  • Send the document to a colleague and they get all the groups and tags — those come from the names — but not your remembered find/replace values.
  • Renaming or moving the document may lose its remembered values. The names in the file still work; you just re-enter the find text.

21Adobe — known limitations

  • Illustrator images must be linked, not embedded. Embedded rasters are skipped and counted.
  • Threaded or linked text across multiple frames may mis-target. Snippet offsets assume one frame per text item. Single-frame labels and paragraphs — the common case — are fine; deeply threaded InDesign stories are not guaranteed.
  • Each apply is its own undo step. There is no single-undo grouping yet, so undoing a big multi-group change means several presses of Ctrl+Z.
  • Item name means the Layers-panel name. Both apps support per-item names; that is the field being read.
